## 说明

- 指标定义：人审量 = 路由到人工复核的条数；最终召回 / 精确率按“自动确认 + 人审判定违规”计算；需调用 LLM = 未被记忆直接研判、需要走研判器的条数（启发式研判时为假想调用数）。
- 记忆只从人审结论写入，自动确认和 LLM 结论不回写；大额（≥10 万）始终人审。
- 数据为合成数据，特征签名由作者按规则设计。结果说明机制有效，不代表真实业务效果。
